# Code of Conduct

## Our Pledge

We as maintainers, contributors, and community members pledge to make participation in this project a respectful, inclusive, and harassment-free experience for everyone.

Regardless of:

- Age
- Body size
- Disability
- Ethnicity
- Gender identity
- Nationality
- Race
- Religion
- Sexual orientation
- Technical experience

everyone is welcome.

---

# Our Standards

Examples of behavior that contributes to a positive environment include:

- Being respectful
- Being constructive
- Helping newcomers
- Accepting feedback gracefully
- Sharing knowledge openly
- Collaborating professionally

Examples of unacceptable behavior include:

- Harassment
- Personal attacks
- Hate speech
- Trolling
- Intimidation
- Publishing private information
- Any discriminatory behavior

---

# Responsibilities of Maintainers

Project maintainers are responsible for:

- Reviewing Pull Requests fairly
- Maintaining a welcoming environment
- Enforcing this Code of Conduct
- Removing inappropriate content when necessary

---

# Scope

This Code of Conduct applies to:

- GitHub Issues
- Pull Requests
- Discussions
- Community interactions
- Project documentation

---

# Enforcement

Instances of abusive or unacceptable behavior may be reported by opening a private discussion with the maintainers.

All complaints will be reviewed and investigated promptly.

Maintainers may take actions including:

- Warning contributors
- Closing discussions
- Rejecting Pull Requests
- Temporarily restricting participation
- Permanently banning repeat offenders
